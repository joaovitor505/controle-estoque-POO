# Controle de Estoque

Sistema de controle de estoque para pequenos comércios, feito em Python, usando Programação Orientada a Objetos (POO) e banco de dados SQLite.

O que o projeto faz

O programa roda no terminal e permite:

- Adicionar um produto (nome, quantidade e preço)
- Listar todos os produtos cadastrados
- Alterar a quantidade de um produto
- Deletar um produto
- Listar produtos com estoque baixo (quantidade menor ou igual a 5)
- Calcular o valor total do estoque, geral e por item

 Tecnologias usadas

- Python
- SQLite (biblioteca `sqlite3`)
- Programação Orientada a Objetos (classe `Produto`)
